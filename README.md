# TTK Creators - Clone

Clone estático da página `https://ttkcreators.click/inicio/`.

## Estrutura de Arquivos

- `index.html`: Página principal com assets e caminhos relativos
- `assets/`: Estilos CSS, ícones, logos e imagens originais
- `scripts-loader.js`: Carregador de scripts e snippets
- `tracking.html`: Estrutura de rastreamento e UTM
- `xtracky.html`: Snippet do manipulador UTM
- `footer.html`: Rodapé dinâmico e scripts
